# Khaldi Abdeldjalil — Portfolio

An interactive isometric city portfolio inspired by [cecibaldoni.github.io](https://cecibaldoni.github.io), personalized with content from [LinkedIn](https://www.linkedin.com/in/khaldi-abdeldjalil-6455852b4/).

## Design

- Same visual tone: warm cream ink palette, forest greens, cinnamon accents
- Same typography: **Roboto Slab** (body) and **Roboto Mono** (headings)
- Custom isometric city with AI/research-themed buildings, mountain backdrop, and animated drone
- Hover-reveal interactive icons linking to portfolio sections

## Local preview

```bash
cd portfolio
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository
2. Enable GitHub Pages from the `main` branch (root directory)
3. Your site will be live at `https://<username>.github.io/<repo>/`

## Customize

- Replace `img/profile.svg` with your photo
- Update project links in `pages/projects.html`
- Add your GitHub URL in the navbar social links
